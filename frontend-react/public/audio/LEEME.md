# Grabaciones de AstroVet

Coloca aquí los audios con voz humana (RNF-11) en formato **MP3**, con el nombre exacto de la lista.
Después agrega el nombre (sin `.mp3`) a `manifiesto.json`, por ejemplo:

```json
{ "archivos": ["vocal-a", "fonema-m", "silaba-ma"] }
```

Mientras un audio no exista, el juego usa la voz del dispositivo. En cuanto el archivo está en la lista, se usa la grabación.

Recomendaciones: la misma voz para todo, ritmo pausado, volumen normalizado (-16 LUFS aprox.), sin ruido de fondo, 0,2 s de silencio al inicio y al final.

Total para los mundos 1 a 3: **66 audios** de contenido. Las frases de Capitán Misi se grabarán en una segunda etapa.
